# 简历生成器

一款功能丰富的在线简历生成工具，支持实时预览、多主题切换、PDF 导出、AI 润色、3D 宇宙版"成长的痕迹"等特色功能。

## 功能特性

- **实时预览**：填写表单时右侧实时同步预览效果
- **多主题切换**：支持水仙花、科技感、毛玻璃、羊皮纸、黑白画廊等多种主题
- **PDF 导出**：一键导出 A4 尺寸 PDF 简历
- **板块排序**：可自由调整各板块的前后顺序
- **AI 润色**：内置语句优化引擎，支持专业精炼、结果导向等多种风格
- **3D 宇宙版"成长的痕迹"**：使用 Three.js 构建沉浸式 3D 星系场景，将人生经历可视化为宇宙星系
- **求职语言库**：内置丰富的求职话术参考库
- **历史记录**：自动保存草稿，支持历史版本恢复

## 文件结构

| 文件 | 说明 |
|------|------|
| `index.html` | 营销落地页 |
| `简历生成器.html` | 主应用 |
| `job_language_lib.js` | 求职语言库 |
| `宇宙场景模块_v3.js` | 3D 宇宙场景模块 |

## 使用方法

直接在浏览器中打开 `简历生成器.html` 即可使用，无需安装任何依赖。

## 技术栈

- 原生 HTML / CSS / JavaScript
- Three.js（3D 宇宙场景）
- html2pdf.js（PDF 导出）
- localStorage（数据持久化）
