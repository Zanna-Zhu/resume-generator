## ✨ 功能特性

### 📝 实时预览
左侧填写表单，右侧同步预览效果。所见即所得，告别来回切换的烦恼。

### 🎨 多主题切换
内置 5+ 精选主题，一键切换整体风格：
- **水仙花** — 清新淡雅，适合文职岗位
- **科技感** — 现代简约，适合互联网行业
- **毛玻璃** — 时尚前卫，适合创意岗位
- **羊皮纸** — 复古文艺，适合人文方向
- **黑白画廊** — 极简专业，适合金融咨询

### 📄 PDF 一键导出
A4 标准尺寸，一键导出高质量 PDF 简历。排版精准，打印即用，告别 Word 排版噩梦。

### 🔄 板块排序
教育、实习、实践、校园……自由调整各板块的前后顺序，突出你的核心优势。

### ✨ AI 语句润色
内置语句优化引擎，支持专业精炼、结果导向等多种风格。让你的经历描述更专业、更有说服力。

### 🌌 3D 宇宙版"成长的痕迹"
使用 Three.js 构建沉浸式 3D 星系场景，将人生经历可视化为宇宙星系：
- 不同阶段 = 不同星系（教育星系、实习星系、实践星系……）
- 不同经历 = 不同星球，点击查看详情
- 鼠标拖动旋转视角，滚轮缩放
- 底部导航按钮在星系间穿梭
- 支持导出为独立 HTML 文件分享

### 💼 求职语言库
内置丰富的求职话术参考库，涵盖自我介绍、项目描述、离职原因等常见场景。

### 💾 本地存储
数据自动保存在浏览器本地，无需注册账号，隐私安全。支持历史版本恢复。

## 🚀 快速开始

### 在线使用（推荐）
直接访问 **[在线体验地址](https://zanna-zhu.github.io/resume-generator/)**，点击"立即使用"即可开始。

### 本地使用
1. 克隆仓库：
   ```bash
   git clone https://github.com/Zanna-Zhu/resume-generator.git
   ```
2. 在浏览器中打开 `简历生成器.html`

> 无需安装任何依赖，无需 Node.js 环境，打开即用。
